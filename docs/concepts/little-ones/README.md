# Little ones: concept rounds

Concept art for the next version of the five starter species. These are sketches, not in the game yet. Open `concepts.html` in a browser to see the latest round rendered live.

## Decisions so far (Director, 2026-11-04)

- **Style: Squishy vinyl.** Glossy, smooth, big soft highlights, like a squeeze toy or vinyl figure. Chosen over Sticker (flat, outlined) and Plush (felt, fuzzy).
- **Roster:**
  - **Cappy**, mushroom: approved as drawn
  - **Pip**, seed: approved as drawn
  - **Blorp**, squishy alien: approved as drawn
  - **Bean**, cuddly cyclops: "looks ok". Stubby mitten feet, no long legs
  - **Oddling**, scraggly yarn ball: brought back from the earlier lineup. Floppy ear, curly antenna, ringed tail
- **Dropped:** the bunny (all three takes)

## Open

- Oddling has one eye, two eyes, or is a wire tangle (see round three)
- Since Bean is the cyclops, should Oddling keep one eye?
